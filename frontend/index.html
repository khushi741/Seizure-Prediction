Model Overview

Dual-Branch Attention & Dilated Temporal Convolutions

Combining Synchronization-Based Attention Mechanism (SBAM) and Multi-Scale Temporal Modeling (MSTM) to forecast neural anomalies before onset.

MSTM + SBAM FUSION NET

NEURAL ELECTRODE SYNCHRONIZATION

The model extracts temporal features across different time steps using dilated causal convolutions in the MSTM branch, while the SBAM branch computes spatial dependencies and cross-channel attention weights dynamically.
⚠️

Label Leakage & Educational Disclosure

The original dataset (train.csv) contains consensus votes from annotators (vote_* columns) that directly leak the target labels. Standard training models reach **98.8% accuracy** by memorizing this leakage.

To witness the true complexity of predicting events from structural data alone, toggle the header to "Leakage-Corrected Mode". This reloads the models trained entirely without leaking variables, revealing a realistic test baseline (~42.2% accuracy).
