Model Scope & Transparency

What This Model Can & Cannot Do

A transparent clinical and engineering appraisal of the classification framework, baseline comparisons, and operational boundaries.

✓ What This Model CAN Do

  • • Demonstrate Catastrophic Label Leakage: Replicates and exposes how annotator vote fractions (vote_*) artificially inflated test accuracy to 98.8%, serving as an educational benchmark in ML hygiene.
  • • Evaluate Honest Baselines: Directly evaluates alongside empirical majority-class (~37.3–42.2%) and logistic regression baselines to establish genuine empirical performance floors.
  • • Enforce Zero Patient Contamination: Validates across patient-isolated partitions (GroupShuffleSplit on patient ID) so unseen patients never contaminate the training split.
  • • Dual-Branch Spatio-Temporal Modeling: Demonstrates multi-head spatial self-attention (SBAM) paired with multi-scale dilated causal temporal convolutions (MSTM).

✕ What This Model CANNOT Do

  • • Cannot Forecast Seizures Minutes Ahead: This Kaggle dataset performs static 50-second pattern classification across 6 electrographic classes; it contains no continuous preictal time series for advance forecasting.
  • • Metadata Features Contain Zero Signal: When vote columns are removed, the remaining tabular columns (eeg_id, offsets, fold) contain no neurological microvolt signals, resulting in majority-class guessing.
  • • Cannot Replace Clinical EEG Monitoring: Standard 10-20 scalp electrode montages and certified clinical interpretation remain mandatory for diagnosis and management.
  • • Not a Medical Device: Must NOT be used for clinical diagnosis, patient monitoring, treatment decisions, or wearable alerting without certified clinical hardware.
Model Overview

Dual-Branch Attention & Dilated Temporal Convolutions

Combining Synchronization-Based Attention Mechanism (SBAM) and Multi-Scale Temporal Modeling (MSTM) to forecast neural anomalies before onset.

MSTM + SBAM FUSION NET

NEURAL ELECTRODE SYNCHRONIZATION

The model extracts temporal features across different time steps using dilated causal convolutions in the MSTM branch, while the SBAM branch computes spatial dependencies and cross-channel attention weights dynamically.
⚠️

Label Leakage & Educational Disclosure

The original dataset (train.csv) contains consensus votes from annotators (vote_* columns) that directly leak the target labels. Standard training models reach **98.8% accuracy** by memorizing this leakage.

To witness the true complexity of predicting events from structural data alone, toggle the header to "Leakage-Corrected Mode". This reloads the models trained entirely without leaking variables, revealing a realistic test baseline (~42.2% accuracy).
